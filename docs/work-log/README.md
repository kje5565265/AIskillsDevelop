# docs/work-log

작업을 그때그때 한 줄로 남기고, **아직 처리하지 않은 보류를 한곳에 모으는** 곳이다.

| 파일 | 무엇 |
|---|---|
| `work-log.md` | 현재 로그. `## 열린 보류` 와 `## 최근 작업` |
| `archive-<시작일>-<종료일>.md` | 잘라낸 지난 기록 |

**아침루틴이 이 폴더를 읽고, 마무리루틴이 갱신한다.**

규칙의 단일 진실원은 **`work-log` 스킬**이다. 줄 형식 · 갱신 · 보류 해소 순서 · 아카이브 기준이 전부 그쪽에 있다. 여기에 복제하지 않는다.
